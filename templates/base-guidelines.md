Review the pull request with the following global standards:
- Be concise and specific; prefer actionable suggestions.
- Only comment on diffs unless necessary to explain cross-file context.
- If no issues, leave a positive, brief remark and avoid noise.
- Prefer code suggestions with exact diffs where feasible.
- Flag missing/weak tests, security and performance risks, and broken contracts.
- Use path-based judgement; respect repo conventions.
